# The World in One Day — 25 November 2026

Entry for make.fun's [“Sum up 25 November's world news in one image”](https://make.fun/bounty/news-image-20261125) bounty.

`main.py` copies `entry.png` (1024×1024) to the output directory
(`MAKEFUN_OUTPUT_DIR` or `/output`). Run it with:

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The image is drawn by `build_image.py` (Pillow) as a front-page style
summary of the day's headlines: Shanghai party chief Chen Jining under
investigation, Huawei convicted on 10 of 12 counts in Brooklyn, a Hamas
security chief killed in Gaza, 25 hostages seized in Colombia, Trump
honouring Giuliani, and a new estimate of 700,000 Russian war dead.
